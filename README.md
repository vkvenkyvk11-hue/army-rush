# Army Rush

**Play: https://vkvenkyvk11-hue.github.io/army-rush/**

Steer the cannon, send troops through x2 / x3 / x5 gates and bring down the enemy fort.
10 levels, coins and upgrades. Works on iPhone (Safari), Android and desktop browsers.
On iPhone: Share -> Add to Home Screen to play it full screen like an app (works offline after the first load).

This repository only holds the exported web build (Godot 4.7.2).
